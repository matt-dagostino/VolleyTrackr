# Volleyball Analysis System 🎯🏐

A cutting-edge computer vision application that uses YOLO (You Only Look Once) and advanced image processing to track volleyballs in real-time, determine ball and player positions, and analyze whether the ball is **in** or **out** during gameplay.

---

## 🚀 Features

- **Real-time ball detection:** Leveraging YOLO object detection to pinpoint volleyball position frame-by-frame.  
- **In/Out line judgment:** Automatically determines if the ball lands inside or outside the court boundaries using spatial analysis.  
- **Trajectory tracking:** Visualizes ball movement and trajectory throughout a rally.  
- **Event tagging:** Detects and logs key volleyball events such as serves, spikes, and faults.  
- **Visual overlays:** Annotated video output with bounding boxes, trajectory paths, and decision indicators.

## ⚙️ Technology Stack

- **YOLOv5/v8:** Real-time object detection framework for fast and accurate volleyball identification.  
- **OpenCV:** Image processing, tracking, and spatial calculations.  
- **Python:** Core programming language for model integration and system control.  
- **NumPy & SciPy:** Mathematical operations and geometry calculations for trajectory and boundary analysis.  
- **Matplotlib:** Visualization of ball trajectories and data analysis outputs.
